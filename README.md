### 🤔 Зачем это нужно?

Обычно, чтобы сгенерировать `UUID`, посчитать `SHA-256`, перевести цвет из `HEX` в `RGB` или декодировать `Base64`, приходится открывать десяток разных сайтов с рекламой и тяжелыми скриптами. 

**MONOLITH** решает это в одной легкой вкладке браузера (отлично подходит как стартовая страница):
- 🔒 **100% локально:** пароли, хеши и строки обрабатываются прямо в браузере через нативный `Web Crypto API` и никуда не отправляются.
- ⚡ **Не грузит систему:** весит всего ~10 КБ, работает без фреймворков и открывается за доли миллисекунды.
- ⌨️ **Удобно как в Linux:** работает автодополнение по `Tab`, история команд по стрелкам `↑ / ↓` и копирование результата в один клик.

### 🛠 Что умеет терминал

| Команда | Что делает | Пример |
| :--- | :--- | :--- |
| `pass [длина]` | Генерирует криптостойкий пароль (от 4 до 128 символов) | `pass 24` |
| `uuid` | Создает уникальный идентификатор `UUID v4` | `uuid` |
| `hash [текст]` | Считает хеш `SHA-256` от любой строки | `hash monolith` |
| `color [код]` | Конвертирует цвета `HEX ↔ RGB` с превью оттенка | `color #10b981` |
| `b64e` / `b64d` | Кодирует и декодирует строки `Base64` (с поддержкой кириллицы) | `b64e Привет` |
| `calc [пример]` | Считает математические выражения, пропорции и пиксели | `calc (1920/16)*9` |
| `time [ts]` | Показывает текущий `Unix Timestamp` или переводит его в дату | `time 1735689600` |
| `sys` | Выводит инфо об экране, потоках CPU и статусе сети | `sys` |
| `theme [имя]` | Меняет цветовую схему (`emerald`, `obsidian`, `nord`, `amber`, `light`) | `theme obsidian` |
| `clear` | Очищает экран консоли | `clear` |
